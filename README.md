# Computer Vision Assignment

## Overview
This repository contains my Computer Vision and Image Processing assignment completed using Python and OpenCV.

## Tasks
1. Introduction to Computer Vision and Image Processing.
2. Loading an image and inspecting dimensions and pixel values.
3. Converting an RGB image to grayscale.
4. Image enhancement and filtering operations.
5. Output images generated during the assignment.

## Tools Used
- Python
- OpenCV
- NumPy
- Online Python environment

## Outputs
The `outputs` folder contains the images generated during the assignment.
